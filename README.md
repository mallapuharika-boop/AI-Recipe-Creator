# AI Recipe Creator 🍳

## Project Description
AI Recipe Creator is a Python-based application that uses the Gemini API to generate recipes based on the ingredients provided by the user.

## Features
- Generate recipes using available ingredients.
- Get AI-powered cooking suggestions.
- Discover new dishes easily.

## Technologies Used
- Python
- Google Gemini API
- Streamlit (if used in the application)

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Configure your Gemini API key.
4. Run the application using Python or Streamlit, depending on your project setup.
